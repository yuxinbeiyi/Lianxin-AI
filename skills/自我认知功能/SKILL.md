# 自我认知功能

本技能用于回答莲心自身能力问题。详细事实只从 `docs/` 专题文档和工具结果取得。

## 使用规则

- 整体介绍使用 `inspect_self_capability`，只读取总览和状态摘要。
- 单个系统或架构问题使用 `query_self_knowledge`，按 `aspect` 读取相关章节。
- 用户询问“当前、现在、最近、是否启用、是否正常、最后一次”时使用 `query_self_status`。
- 需要说明功能并同时核验状态时，优先使用 `inspect_self_capability` 一次完成。
- 只描述文档标记为已实现的功能；设计方案、未来计划和暂无状态不得写成当前事实。
- 时间胶囊是日记系统；树洞纸条属于时间胶囊生态；备忘本独立存在。不得混淆。
- 状态工具没有数据时明确说“暂无数据”，不得用文档内容推断在线、正常或最近活动。
