# Lianxin Desktop Pet V0.1

This is an independent PyQt5 desktop pet prototype. It does not start or
modify the Lianxin main window.

## Run

From the project root, with the `lianxin` environment active:

```powershell
python desktop_pet\run_pet.py
```

Right-click the character to start moving left or right, stop, switch to the
Thinking animation, or exit. Drag the character with the left mouse button.

## Assets

The original design board is kept as `assets/source/character_design.png`.
The runtime frames are transparent `48x64` PNG files generated by:

```powershell
python desktop_pet\tools\crop_sprite_sheet.py
```

The crop coordinates are explicit because the source image is a character
design board rather than a regular sprite sheet. Review the generated frames
before adding more actions.
