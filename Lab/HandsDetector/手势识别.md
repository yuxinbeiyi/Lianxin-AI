# 莲心视觉感知实验室（LianXin Vision Lab）

## 第一阶段：本地手势识别独立测试程序开发方案

### 1. 项目目标

开发一个**完全独立于莲心 AI 主程序**的桌面视觉实验程序，用于验证电脑前置摄像头是否能够稳定、低延迟、低资源地识别用户手势。

第一阶段**不得接入 LLM、大模型、RAG、Agent、莲心主程序或云端视觉 API**。

本阶段只验证：

* OK 手势
* 竖大拇指 👍
* 挥手 👋

最终目标是验证技术可行性，为后续接入莲心视觉感知系统提供稳定的底层模块。

---

## 2. 技术栈

使用：

```text
Python 3.x
PyQt5
OpenCV
MediaPipe
NumPy
```

职责：

| 技术              | 职责           |
| --------------- | ------------ |
| PyQt5           | 桌面 GUI       |
| OpenCV          | 摄像头采集、图像处理   |
| MediaPipe Hands | 手部 21 点关键点检测 |
| NumPy           | 几何计算、轨迹计算    |
| Python          | 业务逻辑、事件管理    |

### 明确禁止

第一阶段不得引入：

```text
Qwen / Qwen-VL
GPT Vision
DeepSeek Vision
任何 LLM
RAG
Agent
MCP
WebRTC
云端视觉 API
人脸识别
表情识别
```

视觉推理优先使用 **CPU**，不要为了手势识别强制占用 RTX 3060。

# 3. 总体架构

采用严格的模块解耦：

```text
                    ┌────────────────────┐
                    │    CameraManager   │
                    │   OpenCV 摄像头    │
                    └─────────┬──────────┘
                              ↓
                    ┌────────────────────┐
                    │    HandDetector    │
                    │ MediaPipe Hands    │
                    └─────────┬──────────┘
                              ↓
                    ┌────────────────────┐
                    │ GestureClassifier  │
                    │ OK / 👍 / 👋 / None │
                    └─────────┬──────────┘
                              ↓
                    ┌────────────────────┐
                    │   GestureState     │
                    │ 连续帧确认/去抖     │
                    └─────────┬──────────┘
                              ↓
                    ┌────────────────────┐
                    │    EventManager    │
                    │ 冷却/事件触发       │
                    └─────────┬──────────┘
                              ↓
              ┌───────────────┴──────────────┐
              ↓                              ↓
       实时日志系统                     MockLianXin
                                      模拟莲心回复
```

**GUI 不得直接参与视觉识别逻辑。**

GUI 只负责：

* 显示摄像头画面
* 显示识别结果
* 显示运行状态
* 显示日志
* 控制启动/停止/暂停

## 8.1 OK 手势

识别特征：

* 拇指与食指指尖接触或距离很近
* 形成近似圆形
* 中指、无名指、小拇指保持伸展

内部统一名称：

```python

```

```text

```

模拟回复：

```text
收到～
```

# 9. THUMBS_UP

识别特征：

* 拇指向上伸展
* 其余四指主要弯曲

```python
THUMBS_UP
```

触发：

```text
检测到 👍 手势
```


# 10. WAVE

挥手属于**动态手势**，不得通过单帧判断。

需要保存最近一段时间的手掌中心轨迹。

例如：

```text
x1 → x2 → x3 → x2 → x1
```

或者：

```text
← → ← →
```

在时间窗口内出现明显左右往返运动，才判定：

```python
WAVE
```

模拟回复：

```text
拜拜，一会儿见～
```

# 12. 连续帧确认机制

禁止单帧直接触发事件。

例如：

```text
OK
OK
OK
↓
确认 OK
```

建议默认：

```text
连续 3～5 帧
```

识别结果相同后才确认。

配置项：

```python
GESTURE_CONFIRM_FRAMES = 4
```

允许后续调整。

---

# 13. 2 秒冷却机制

任何手势事件触发后：

```text
2 秒内不得再次触发同类事件。
```

但是：

**冷却期间视觉识别不能停止。**

错误做法：

```python
trigger()
sleep(2)
```

禁止阻塞识别线程。

正确方式：

```text
事件触发
↓
记录 trigger_time
↓
继续实时识别
↓
判断：
current_time - trigger_time >= cooldown
↓
允许再次触发
```

默认：

```python
GESTURE_COOLDOWN = 2.0
```


然后发送给：

# 17. 摄像头线程

禁止在 PyQt UI 主线程执行摄像头循环。

采用：

```text
PyQt 主线程
        │
        ├── UI
        │
        └── Worker Thread
                │
                ├── OpenCV
                ├── MediaPipe
                └── GestureClassifier
```

要求：

* UI 不冻结
* 摄像头异常不能导致程序崩溃
* 关闭摄像头后正确释放资源
* 程序退出时确保 `VideoCapture.release()`

# 26. 最终架构原则

整个第一阶段只验证：

> **摄像头 → 本地视觉识别 → 手势事件 → 模拟莲心回复**

最终结构必须保持：

```text
Camera
  ↓
MediaPipe Hands
  ↓
Gesture Classifier
  ↓
Gesture State
  ↓
Event Manager
  ↓
┌───────────────┐
│               │
↓               ↓
GUI Logger   MockLianXin
```

**不要让任何视觉模块直接调用 LLM。**

未来接入莲心时：

```text
Gesture Event
      ↓
LianXin Vision Event Bus
      ↓
莲心现有 Agent / 对话系统
```

即可完成集成，而无需重写底层手势识别模块。
